## Agent skills

### Issue tracker

Issues live in Linear (Guru project), accessed via the Linear MCP server. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout (root `CONTEXT.md` + `docs/adr/`). See `docs/agents/domain.md`.

### Commit messages

Use Conventional Commits without scopes. Feature commits use the form
`feat: describe the feature`; do not use forms such as `feat(scope): ...`.
